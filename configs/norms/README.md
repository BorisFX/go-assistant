# Нормативная база (корпус)

Папка с полными текстами нормативных актов, которые бот индексирует и из
которых координатор юр-ревью и инструмент `norm_search` берут цитаты.
Без загруженного текста модель не имеет права ссылаться на пункт нормы.

## Где лежит

Путь задаётся в конфиге инстанса:

```yaml
legal_review:
  norms_dir: /opt/assistant-yuri/knowledge/norms
```

## Форматы файлов

`.md`, `.txt` (предпочтительно), `.pdf` (через `pdftotext -layout`),
`.docx` (через LibreOffice). Один файл — один документ. Подпапки не читаются.

Текст должен сохранять нумерацию единиц как в оригинале, по ней режутся
чанки и строятся ссылки:

- законы и кодексы: `Статья 26. ...`, части `1. ...`, пункты `7) ...`
  → ссылки `ст. 26`, `ст. 26 ч. 1`, `ст. 26 ч. 1 п. 7`;
- СП/ГОСТ/СанПиН: `4.3 ...`, `6.1.2 ...` → `п. 4.3`, `п. 6.1.2`;
- `Приложение А` → `Приложение А`.

## manifest.yaml

Необязателен. Без него код документа = имя файла без расширения.
С ним можно указать редакцию и источник, они попадают в каждую цитату:

```yaml
218-fz.md:
  code: 218-ФЗ
  title: О государственной регистрации недвижимости
  edition: ред. от 08.08.2024
  source: consultant.ru
sp-4-13130-2013.pdf:
  code: СП 4.13130.2013
  title: Системы противопожарной защиты. Ограничение распространения пожара
  edition: с изм. 1-3 (2020)
  source: файл Юрия
```

Рекомендуемые коды: `218-ФЗ`, `ГрК РФ`, `ЗК РФ`, `ГК РФ`, `ПП 87`,
`СП 4.13130.2013`, `СП 42.13330.2016`, `СП 56.13330.2021`, `СП 118.13330.2022`,
`СП 59.13330.2020`. При поиске код совпадает по префиксу: «СП 4.13130» найдёт
«СП 4.13130.2013».

## Загрузка

```bash
/opt/assistant-yuri/assistant --config /opt/assistant-yuri/config.yaml --ingest-norms
```

Повторный запуск переиндексирует только файлы, у которых изменился хэш.
Каждый чанк получает эмбеддинг (модель из `llm.embedding`), поэтому первая
загрузка большого СП занимает минуты.

## Проверка

В Telegram: «что говорит п. 4.3 СП 4.13130» — бот должен вызвать
`norm_search` и процитировать текст с указанием редакции. Если документа нет,
ответ обязан содержать «текст нормы не загружен в базу».
